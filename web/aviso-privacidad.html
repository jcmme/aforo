Datos personales que se recaban

Finalidades

  • Primarias: crear y administrar la cuenta, gestionar reservas y códigos de acceso, operar el control de entrada de los establecimientos afiliados.
  • Prevención de fraude: detección de reservas incumplidas reiteradas (no-shows) para proteger la operación de los establecimientos. Los identificadores de dispositivo NO se usan para publicidad ni se comparten con terceros.

Derechos ARCO

El titular puede ejercer sus derechos de Acceso, Rectificación, Cancelación y Oposición escribiendo a [correo]. Transferencias

Los datos operativos de una reserva (nombre y estado de llegada) son visibles para el establecimiento donde se reservó, exclusivamente para operar el acceso. No se venden ni comparten datos con terceros para fines publicitarios.
